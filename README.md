# 💻 Meu Portfólio Pessoal — Dark Tech Mode

Bem-vindo ao repositório do meu portfólio pessoal! Este é um projeto focado em um design moderno, minimalista e com estética voltada para tecnologia (estilo *Cyber Punk / Terminal Pro*). 

O principal objetivo deste projeto é revisar, praticar e consolidar os **conceitos fundamentais de HTML5 e CSS3 puros**, criando uma estrutura sólida e uma estilização limpa sem o uso de frameworks.

---

## 🎨 Identidade Visual & Design

O projeto foi construído utilizando uma paleta de cores balanceada para o modo escuro, garantindo boa legibilidade, contraste e uma atmosfera de terminal de desenvolvimento.

*   **Fundo Principal:** `#0B0F19` (Azul-escuro profundo)
*   **Fundo Secundário (Cards/Menus):** `#161B26` (Cinza-azulado para blocos de conteúdo)
*   **Texto Principal:** `#E2E8F0` (Branco acinzentado para conforto visual)
*   **Cor de Destaque (Accent):** `#00F5FF` (Ciano Neon para botões, links e efeitos de foco)

### 🔤 Tipografia
As fontes foram importadas diretamente do Google Fonts para reforçar o aspecto tecnológico:
*   **Títulos:** `Space Grotesk` (Geométrica e marcante)
*   **Texto Geral:** `Space Grotesk` / Sans-serif
*   **Tags e Elementos de Código:** `Fira Code` (Monoespacada estilo terminal)

---

## 🚀 Tecnologias Utilizadas

*   **HTML5:** Estruturação semântica das seções (Header, Main, Sections, Footer).
*   **CSS3:** Estilização avançada, uso de CSS Variables (variáveis de cores), Flexbox para alinhamento, efeitos de transição (`transition`) e efeitos visuais como *Glow* e *Glassmorphism*.
*   **Git & GitHub:** Controle de versão e hospedagem do código.
